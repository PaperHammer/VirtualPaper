# VirtualPaper：隐私、AI 处理与版权说明

文档版本：1.0。更新日期：2026-11-15。发布者及项目维护者：PaperHammer。

本说明适用于 VirtualPaper 的 EXE 安装版和 Microsoft Store 版，介绍应用如何处理数据，以及使用 AI 功能和内置素材时需要了解的权利事项。外部网站和服务适用各自的政策。

<a id="privacy-policy"></a>
## 隐私政策

### 本地文件与设置

VirtualPaper 会读取您选择的图片、视频、动态图像和 Web 项目，用于显示、编辑或处理。壁纸信息、缩略图、收藏、标签、效果预设、最近使用的项目路径、应用设置和显示器布局均保存在本机。使用应用无需注册 VirtualPaper 账号；应用不会为了 AI 处理、广告或行为分析，将这些素材和记录上传给 PaperHammer。

默认数据目录为 `%LOCALAPPDATA%\VirtualPaper`；在封装版本中，Windows 可能将数据重定向到其他本地位置。壁纸库保存在设置中指定的位置，导出的项目和图片保存在您选择的位置。预览、撤销操作、深度图和浏览器缓存也可能产生本地文件。这些数据不会自动备份到云端。

### 诊断与问题报告

本地日志可能记录应用和 Windows 版本、界面语言、CPU／GPU 信息、错误、文件路径和播放情况。导出日志时，应用会在本机生成包含日志、用户设置和壁纸布局的 ZIP 压缩包，不会自动发送给 PaperHammer。分享前请检查其中的内容，文件路径可能包含您的 Windows 用户名或私人项目名称。您主动提交到 GitHub 的问题报告和附件由 GitHub 处理，并可能公开显示。

### 位置信息

启用“时间感知”后，应用会请求 Windows 定位权限，使用经纬度在本机计算日出和日落时间。无法获取位置时，应用会使用默认位置，此时光照变化可能与您所在地区不一致。关闭“时间感知”可停止该功能请求位置；您也可以在 Windows 的“隐私和安全性”设置中管理定位权限。用于计算的坐标不会发送给 PaperHammer。

### 联网与第三方服务

EXE 版可连接 GitHub 和下载服务器，检查及获取应用或插件更新；安装时可能下载 Microsoft 运行时依赖。商店版的分发和更新由 Microsoft 处理。网络请求会向接收方暴露 IP 地址、请求头等连接信息。打开帮助、反馈或源码链接会连接相应网站。Web 壁纸和导入的 Web 项目可能独立加载其作者控制的远程脚本、媒体或服务。

WebView2 的诊断功能和 SmartScreen 会向 Microsoft 发送相关信息，详见 [Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)。部分诊断报告由 Windows 诊断设置控制。VirtualPaper 的 AI 处理在本机执行，不通过这些功能上传您的素材进行 AI 处理。

### 保存期限、安全与您的选择

已保存的设置、壁纸库、项目、深度图缓存和浏览器配置保存在本机，直到您主动删除，或应用在清理、卸载时将其移除。AI 任务和编辑器的临时结果可能在下次启动时被清理；需要保留的内容，请及时保存或添加到壁纸库。部分日志和缓存没有固定的自动清理期限。卸载应用后，迁移到其他位置的壁纸库和已导出的文件仍可能保留。

您可以查看、导出、修改或删除本地文件，并调整相关设置。手动删除应用数据前，请先退出 VirtualPaper 及其后台进程，并备份需要保留的文件。本地数据由 Windows 账号和文件系统权限保护，VirtualPaper 不提供额外的加密存储。请妥善保护您的 Windows 账号，并仅使用可信的壁纸项目。

### 联系与政策更新

如有隐私问题，或需要查询、更正、删除您主动向项目提交的信息，请通过 [GitHub Issues](https://github.com/PaperHammer/VirtualPaper/issues) 联系 PaperHammer。请勿在公开问题中附上敏感信息，可先询问合适的联系方式。由 GitHub、Microsoft 或壁纸所使用的外部服务持有的信息，应按相应服务的规则管理。应用的数据处理方式发生变化时，我们会更新本说明；您可以通过文档版本和日期确认所阅读的版本。
