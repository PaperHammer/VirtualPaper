# VirtualPaper: 개인정보, AI 처리 및 저작권 안내

문서 버전: 1.0. 업데이트: 2026-11-15. 게시자 및 프로젝트 관리자: PaperHammer.

이 문서는 VirtualPaper의 EXE 설치 버전과 Microsoft Store 버전이 데이터를 처리하는 방식, 그리고 AI 기능과 내장 콘텐츠를 사용할 때 알아두어야 할 권리를 설명합니다. 외부 웹사이트와 서비스에는 각자의 정책이 적용됩니다.

<a id="privacy-policy"></a>
## 개인정보 처리방침

### 로컬 파일과 설정

VirtualPaper는 사용자가 선택한 사진, 동영상, 움직이는 이미지 및 Web 프로젝트를 읽어 표시하거나 편집 또는 처리합니다. 배경화면 메타데이터, 미리 보기 이미지, 즐겨찾기, 태그, 효과 프리셋, 최근 프로젝트 경로, 설정 및 모니터 배치는 로컬에 저장됩니다. VirtualPaper 계정을 만들 필요가 없으며, AI 추론이나 광고 또는 행동 분석을 위해 이러한 자료와 기록을 관리자에게 업로드하지 않습니다.

기본 데이터 폴더는 `%LOCALAPPDATA%\VirtualPaper`이며, 패키지 앱의 데이터는 Windows에서 리디렉션할 수 있습니다. 배경화면 라이브러리는 설정에서 선택한 위치를, 내보낸 프로젝트와 이미지는 사용자가 선택한 위치를 사용합니다. 미리 보기, 실행 취소, 깊이 맵 및 브라우저 데이터로 추가 로컬 파일이 생성될 수 있습니다. 이 파일들은 클라우드 백업이 아닙니다.

### 진단 및 문제 보고

로컬 로그에는 앱과 Windows 버전, 인터페이스 언어, CPU/GPU 정보, 오류, 파일 경로 및 재생 정보가 포함될 수 있습니다. 로그 내보내기는 로그, 사용자 설정 및 배경화면 배치를 포함하는 ZIP 파일을 로컬에 생성하며 PaperHammer에 자동으로 전송하지 않습니다. 경로에 Windows 사용자 이름이나 비공개 프로젝트 이름이 드러날 수 있으므로 공유 전에 확인하세요. 사용자가 GitHub에 자발적으로 게시한 보고서와 첨부 파일은 GitHub가 처리하며 공개될 수 있습니다.

### 위치 정보

시간 감지 기능을 켜면 앱은 Windows 위치 권한을 요청하고 위도와 경도로 기기에서 일출과 일몰을 계산합니다. 권한이 없으면 기본 위치를 사용하므로 조명 변화가 해당 지역과 다를 수 있습니다. 이 기능을 끄면 해당 위치 요청이 중지되며, Windows의 개인정보 및 보안 설정에서도 권한을 관리할 수 있습니다. VirtualPaper는 이 계산을 위해 좌표를 관리자에게 전송하지 않습니다.

### 네트워크 및 타사 서비스

EXE 버전은 앱이나 플러그인 업데이트를 확인하고 받기 위해 GitHub 및 다운로드 호스트에 연결할 수 있습니다. 설치 중 Microsoft 런타임 종속 항목을 다운로드할 수 있습니다. Store 배포와 업데이트는 Microsoft가 처리합니다. 네트워크 요청은 IP 주소와 요청 헤더 같은 연결 정보를 수신자에게 노출합니다. 도움말, 피드백 또는 소스 링크를 열면 해당 사이트에 연결합니다. Web 배경화면 및 가져온 Web 프로젝트는 작성자가 제어하는 외부 스크립트, 미디어 또는 서비스를 별도로 불러올 수 있습니다.

WebView2 진단 및 SmartScreen은 Microsoft에 정보를 전송합니다. [Microsoft 개인정보처리방침](https://privacy.microsoft.com/privacystatement)을 확인하세요. 일부 보고에는 Windows 진단 설정이 적용됩니다. 이는 VirtualPaper의 로컬 AI 추론과 별개입니다.

### 보관, 보안 및 선택권

저장한 설정, 라이브러리, 프로젝트, 깊이 캐시 및 브라우저 프로필은 사용자가 삭제하거나 해당 정리 또는 제거 작업으로 삭제될 때까지 로컬에 남습니다. 임시 AI 또는 편집 결과는 다음 실행 때 지워질 수 있으므로 보관하려면 저장하거나 라이브러리에 추가하세요. 모든 로그와 캐시에 고정된 자동 삭제 기간이 있는 것은 아닙니다. 앱 제거가 다른 위치로 옮긴 라이브러리나 내보낸 파일의 삭제를 보장하지는 않습니다.

로컬 파일을 확인, 내보내기, 수정 또는 삭제하고 관련 설정을 바꿀 수 있습니다. 앱 데이터를 수동으로 삭제하기 전에는 VirtualPaper와 백그라운드 프로세스를 종료하고 필요한 파일을 백업하세요. 로컬 데이터는 Windows 계정과 파일 시스템 권한으로 보호되며 별도의 암호화 보관함은 제공하지 않습니다. 신뢰할 수 있는 배경화면 프로젝트를 사용하고 Windows 계정을 보호하세요.

### 연락 및 변경

개인정보에 관한 질문이나 프로젝트에 자발적으로 제공한 정보에 대한 요청은 [GitHub Issues](https://github.com/PaperHammer/VirtualPaper/issues)를 통해 PaperHammer에 문의하세요. 민감한 정보를 공개하지 말고 적절한 제공 방법을 먼저 문의하세요. GitHub, Microsoft 또는 배경화면 외부 서비스가 보유한 정보에는 해당 제공자의 관리 방식이 적용됩니다. 관련 앱 동작이 변경되면 이 안내를 업데이트하며, 버전과 날짜로 앱에 포함된 사본을 식별합니다.

<a id="ai-processing-and-rights"></a>
## AI 처리 및 권리 안내

깊이 추정, 스타일 변환 및 이미지 향상은 컴퓨터에 있는 모델을 사용하며 기능과 설정에 따라 CPU/GPU에서 실행합니다. 클라우드 AI 서비스를 호출하지 않으며 모델 파일이 로컬에 있어야 합니다. 품질과 속도는 원본, 모델 및 하드웨어에 따라 다릅니다. 생성된 세부 내용이 부정확할 수 있으며 깊이 맵은 측정값이 아닌 추정값입니다.

AI로 처리했다는 사실만으로 원본이나 처리 결과의 저작권을 얻거나 타인의 자료를 사용할 허가를 받는 것은 아닙니다. 결과가 저작권으로 보호되는지, 누가 권리를 갖는지는 적용 법률, 원본 자료의 이용 조건과 사람의 창작적 기여에 따라 달라집니다. 기존의 이용 제한은 AI 처리 후에도 자동으로 사라지지 않습니다. 공개, 재배포 또는 상업적 이용 전에 해당 용도에 필요한 권리나 허가를 갖추었는지 확인하세요. 저작권, 초상권, 상표권 등 타인의 권리도 고려해야 합니다.

VirtualPaper는 앱을 사용했다는 이유만으로 입력 자료나 결과의 소유권을 주장하지 않습니다. 소프트웨어의 오픈 소스 라이선스가 사용자 자료나 출력물에 자동으로 GPL을 적용하지는 않습니다. 모델/런타임 라이선스와 원본 이미지의 허락은 별개입니다. 무료 모델이라고 해서 모든 출력물을 제한 없이 사용할 수 있는 것은 아닙니다. 권리 비침해, 독점성 또는 상업적 적합성을 보장하지 않습니다. 이 안내는 필요한 허락을 대신하거나 법률이 부여하는 권리를 제한하지 않습니다.

일부 내장 풍경 배경화면은 모음 제작 당시 OpenAI 이미지 생성으로 만들었습니다. 앱의 로컬 추론 기능과는 별개이며 사용자의 이미지를 OpenAI에 보낸다는 뜻이 아닙니다. 각 배경화면의 안내에 출처와 이용 조건이 있으며, 해당 AI 생성 이미지에 독점 저작권을 주장하지 않습니다.

타사 구성 요소와 모델 가중치에는 각각의 저작권 고지와 라이선스가 적용됩니다. [타사 소프트웨어 및 자료 안내](../THIRD-PARTY.txt)와 함께 제공되는 라이선스 및 NOTICE 원문을 확인하세요. 번역과 설명은 참고용이며, 원문의 조건을 대신하거나 모든 타사 자료에 대한 이용 허가를 부여하지 않습니다.

CC0는 출처 표시를 의무로 요구하지 않습니다. 제작자와 출처 기록은 이력 보존을 위한 것이며 재배포 조건을 추가하지 않습니다.
