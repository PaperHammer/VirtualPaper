# VirtualPaper：隱私、AI 處理與著作權說明

文件版本：1.0。更新日期：2026-11-15。發行者及專案維護者：PaperHammer。

本說明適用於 VirtualPaper 的 EXE 安裝版與 Microsoft Store 版，介紹應用程式如何處理資料，以及使用 AI 功能和內建素材時應瞭解的權利事項。外部網站與服務適用各自的政策。

<a id="privacy-policy"></a>
## 隱私權政策

### 本機檔案與設定

VirtualPaper 會讀取您選擇的圖片、影片、動態影像與 Web 專案，用於顯示、編輯或處理。桌布資訊、縮圖、收藏、標籤、效果預設、最近使用的專案路徑、應用程式設定與螢幕配置均儲存在本機。使用應用程式無須註冊 VirtualPaper 帳號；應用程式不會為了 AI 處理、廣告或行為分析，將這些素材與紀錄上傳給 PaperHammer。

預設資料目錄為 `%LOCALAPPDATA%\VirtualPaper`，封裝應用程式的資料可能由 Windows 重新導向。桌布庫可使用設定中選定的位置；匯出的專案與圖片保存在您選擇的位置。預覽、復原、深度圖與瀏覽器資料可能產生額外的本機檔案。這些檔案並非雲端備份。

### 診斷與問題回報

本機記錄可能包含應用程式及 Windows 版本、介面語言、CPU／GPU 資訊、錯誤、檔案路徑與播放情況。匯出記錄會在本機建立 ZIP，包含記錄、使用者設定與桌布配置，不會自動傳送給 PaperHammer。分享前請檢查壓縮檔：路徑可能透露 Windows 使用者名稱或私人專案名稱。您主動提交至 GitHub 的回報與附件由 GitHub 處理，且可能公開。

### 位置資訊

啟用時間感知後，應用程式會要求 Windows 定位權限，使用經緯度在本機計算日出與日落時間。無法取得位置時會使用預設位置，光照變化可能與您所在的地區不同。關閉時間感知可停止此功能要求位置；您也可以在 Windows「隱私權與安全性」設定中管理定位權限。用於計算的座標不會傳送給 PaperHammer。

### 網路連線與第三方服務

EXE 版可連線至 GitHub 與下載伺服器，檢查及取得應用程式或外掛程式更新；安裝時可能下載 Microsoft 執行階段相依項目。商店版的發行與更新由 Microsoft 處理。網路要求會向接收方揭露 IP 位址、要求標頭等連線資訊。開啟說明、意見反應或原始碼連結會連線至相關網站。Web 桌布與匯入的 Web 專案可能自行載入其作者控制的遠端指令碼、媒體或服務。

WebView2 的診斷與 SmartScreen 會向 Microsoft 傳送資訊，詳見 [Microsoft 隱私權聲明](https://privacy.microsoft.com/privacystatement)；部分回報受 Windows 診斷設定控制。這些元件行為與 VirtualPaper 的本機 AI 推論不同。

### 保存期間、安全與您的選擇

已儲存的設定、桌布庫、專案、深度圖快取與瀏覽器設定檔會保留在本機，直到您主動刪除，或應用程式在清理、解除安裝時將其移除。AI 任務與編輯器的暫存結果可能在下次啟動時清除；需要保留的內容，請及時儲存或加入桌布庫。部分記錄與快取沒有固定的自動清理期限。解除安裝後，移至其他位置的桌布庫與已匯出的檔案仍可能保留。

您可以檢視、匯出、修改或刪除本機檔案，並調整相關設定。手動刪除應用程式資料前，請結束 VirtualPaper 及背景處理程序，並備份要保留的檔案。本機資料依靠 Windows 帳號與檔案系統權限保護，VirtualPaper 不提供獨立的加密保管庫。請使用可信任的桌布專案並保護本機帳號。

### 聯絡與政策更新

如有隱私問題，或希望處理您主動提供給專案的資訊，請透過 [GitHub Issues](https://github.com/PaperHammer/VirtualPaper/issues) 聯絡 PaperHammer。請勿公開張貼敏感資訊，應先詢問適當的提供方式。GitHub、Microsoft 或桌布外部服務持有的資訊，依相應提供者的規則管理。應用程式相關行為變更時會更新本說明；版本與日期用於識別隨應用程式提供的副本。

## AI 處理與權利說明

深度估計、風格轉換與影像增強均使用儲存在本機的模型，依功能與設定由 CPU 或 GPU 執行，不呼叫雲端 AI 服務。處理效果與時間取決於原始素材、模型與硬體。AI 補充的細節可能與真實內容不符，深度圖也只是估計結果，並非實際測量值。

經過 AI 處理，不代表您就擁有原始素材或處理結果的著作權，也不代表取得了使用他人素材的許可。處理結果能否受到著作權保護、權利由誰享有，取決於適用法律、原始素材的授權條件與人的原創性貢獻。AI 處理不會自動消除素材原有的權利限制。公開發表、再散布或商業使用前，請確認您擁有相應用途所需的權利或許可，並留意著作權、肖像權、商標權等第三方權利。

VirtualPaper 不會因為您使用本應用程式，就主張對您的輸入素材或處理結果享有所有權。應用程式碼採用的 GPL 開放原始碼授權不會自動適用於您的素材或輸出檔案。模型、執行階段元件與原始圖片的授權須分別考量；模型可免費下載，不代表處理結果可以不受限制地使用。VirtualPaper 不保證結果未侵害第三方權利，也不保證其具有專有性或適合商業用途。本說明無法取代必要授權，也不會限制法律賦予您的權利。

部分內建風景桌布由專案在準備素材時使用 OpenAI 影像生成功能製作，來源與使用條件請見各桌布隨附的說明。專案不對這些 AI 生成影像主張專有著作權。內建素材的製作過程與應用程式的本機 AI 處理各自獨立，您的圖片不會因此傳送給 OpenAI。
