# VirtualPaper：プライバシー、AI 処理、著作権

文書バージョン：1.0。更新日：2026-11-15。発行者およびプロジェクト管理者：PaperHammer。

本書では、VirtualPaper の EXE 版と Microsoft Store 版でのデータの取り扱いと、AI 機能や内蔵素材を使う際に確認していただきたい権利について説明します。外部のサイトやサービスには、それぞれのポリシーが適用されます。

<a id="privacy-policy"></a>
## プライバシーポリシー

### ローカルファイルと設定

VirtualPaper は、選択した画像、動画、アニメーション画像、Web プロジェクトを読み取り、表示、編集、処理します。壁紙のメタデータ、サムネイル、お気に入り、タグ、効果プリセット、最近のプロジェクトのパス、設定、モニター配置は端末に保存されます。VirtualPaper アカウントの登録は不要です。AI 推論、広告、行動分析のために、これらの素材や記録を管理者へアップロードすることはありません。

既定のデータフォルダーは `%LOCALAPPDATA%\VirtualPaper` です。パッケージ版のデータは Windows によってリダイレクトされる場合があります。壁紙ライブラリは設定で指定した場所、書き出したプロジェクトや画像は選択した場所に保存されます。プレビュー、元に戻す操作、深度マップ、ブラウザーのデータによって追加のローカルファイルが作成される場合があります。これらはクラウドバックアップではありません。

### 診断と問題報告

ローカルログには、アプリと Windows のバージョン、表示言語、CPU／GPU 情報、エラー、ファイルパス、再生状況が含まれる場合があります。ログのエクスポートでは、ログ、ユーザー設定、壁紙の配置を含む ZIP が端末に作成されます。PaperHammer に自動送信されることはありません。パスから Windows ユーザー名や非公開プロジェクト名が分かる場合があるため、共有前に確認してください。GitHub に自主的に投稿した報告や添付ファイルは GitHub が取り扱い、公開される場合があります。

### 位置情報

時間連動機能を有効にすると、アプリは Windows の位置情報の許可を求め、緯度と経度を端末上で使用して日の出と日の入りを計算します。利用できない場合は既定の位置を使用するため、明るさの変化が地域と一致しない場合があります。この機能を無効にすると位置情報の要求を停止できます。許可は Windows の「プライバシーとセキュリティ」でも管理できます。この計算のために座標を管理者へ送信することはありません。

### ネットワークと第三者サービス

EXE 版は、アプリやプラグインの更新確認・取得のため GitHub やダウンロードサーバーへ接続する場合があります。インストール時には Microsoft のランタイムをダウンロードする場合があります。Store 版の配信と更新は Microsoft が処理します。通信先には IP アドレスやリクエストヘッダーなどの接続情報が伝わります。ヘルプ、フィードバック、ソースコードのリンクを開くと、該当サイトに接続します。Web 壁紙や読み込んだ Web プロジェクトは、作者が管理する外部スクリプト、メディア、サービスを独自に読み込む場合があります。

WebView2 の診断と SmartScreen は Microsoft に情報を送信します。[Microsoft のプライバシー声明](https://privacy.microsoft.com/privacystatement)をご確認ください。一部の報告は Windows の診断設定に従います。これらの動作は VirtualPaper のローカル AI 推論とは別です。

### 保存期間、安全性、選択肢

保存した設定、ライブラリ、プロジェクト、深度キャッシュ、ブラウザープロファイルは、自分で削除するか、該当するクリーンアップやアンインストール処理によって削除されるまで端末に残ります。AI や編集の一時的な結果は次回起動時に消去される場合があります。残したい結果は保存するかライブラリへ追加してください。すべてのログやキャッシュに固定の自動削除期限があるわけではありません。アンインストールしても、移動済みのライブラリや書き出したファイルが必ず削除されるとは限りません。

ローカルファイルの確認、エクスポート、修正、削除や、関連設定の変更ができます。アプリのデータを手動で削除する前に、VirtualPaper とバックグラウンドプロセスを終了し、必要なファイルをバックアップしてください。データの保護は Windows アカウントとファイルシステムのアクセス権に依存し、専用の暗号化保管庫は提供しません。信頼できる壁紙プロジェクトを使用し、Windows アカウントを保護してください。

### お問い合わせと更新

プライバシーに関する質問や、自主的にプロジェクトへ提供した情報についての依頼は、[GitHub Issues](https://github.com/PaperHammer/VirtualPaper/issues) から PaperHammer へお問い合わせください。機密情報は公開せず、適切な提供方法を先に確認してください。GitHub、Microsoft、壁紙の外部サービスが保有する情報には各提供者の管理方法が適用されます。関連するアプリの動作が変わった際には本説明を更新します。バージョンと日付はアプリに付属する文書を識別します。

<a id="ai-processing-and-rights"></a>
## AI 処理と権利について

深度推定、スタイル変換、画像の高画質化は端末上のモデルを使用し、機能と設定に応じて CPU／GPU で実行します。クラウド AI サービスは呼び出しません。モデルファイルは端末に必要です。品質や速度は元の素材、モデル、ハードウェアによって異なります。生成された細部には誤りがあり得ます。深度マップは測定値ではなく推定です。

AI で処理しただけで、元の素材や処理結果の著作権、または他人の素材を利用する許可が得られるわけではありません。結果が著作権で保護されるか、誰がその権利を持つかは、適用される法律、元の素材の利用条件、人による創作的な貢献によって異なります。元の素材にある利用制限は、AI 処理後も自動的にはなくなりません。公開、再配布、商用利用の前に、目的に応じた権利や許可があることをご確認ください。著作権、肖像権、商標権など、第三者の権利にも配慮が必要です。

VirtualPaper は、アプリの利用だけを理由に入力素材や結果の所有権を主張しません。ソフトウェアのオープンソースライセンスが、素材や出力を自動的に GPL の対象にすることはありません。モデル・ランタイムのライセンスと元画像の許諾は別です。無料で入手できるモデルでも、すべての出力を無制限に利用できるとは限りません。権利非侵害、独占性、商用利用への適合は保証しません。本説明は必要な許諾の代わりにはならず、法令で認められる権利を制限しません。

内蔵の風景壁紙の一部は、素材集の準備時に OpenAI の画像生成を使って制作されました。これはアプリのローカル推論機能とは別であり、ユーザーの画像を OpenAI へ送信するという意味ではありません。個別の説明に来歴と利用条件を記載し、これらの AI 生成画像に独占的な著作権は主張しません。
